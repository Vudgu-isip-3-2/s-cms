# Калькулятор заказов кафе (Web-версия)

## Функциональные требования
- Добавление/удаление позиций заказа
- Указание названия, цены, количества
- Коды скидок: SAVE10 (10%), SAVE20 (20%), WELCOME (50 руб.)
- Расчёт налога (по умолчанию 10%)
- Расчёт чаевых в процентах
- Вывод детального результата

## Технологии
- HTML5, CSS3, JavaScript (ES6+)
- Без внешних библиотек

## Примечание
Используется `let` и стрелочные функции.
