## Общая архитектура

Класс PageSorter реализует механизм сортировки элементов списка с использованием технологии drag-and-drop на чистом JavaScript.

Основные возможности:
- изменение порядка элементов списка с помощью мыши
- визуальная индикация перетаскивания
- сохранение порядка элементов в localStorage
- восстановление порядка после перезагрузки страницы

---

## Структура HTML

Для работы класса требуется список следующего вида:

```html
<ul id="page-list">
  <li data-id="1">Главная</li>
  <li data-id="2">О нас</li>
  <li data-id="3">Блог</li>
</ul>

Особенности:

список должен быть представлен элементом <ul> или <ol>
каждый элемент <li> должен содержать атрибут data-id
data-id используется для сохранения порядка
Компоненты класса
1. Конструктор
new PageSorter(options)

Конструктор выполняет:

поиск DOM-элемента списка
сохранение настроек
запуск инициализации
загрузку сохранённого порядка

Параметры:

listSelector — CSS-селектор списка
useLocalStorage — включает сохранение порядка
2. Метод init()

Метод отвечает за настройку drag-and-drop поведения.

Основные действия:

Получение всех элементов списка (li)
Установка атрибута draggable
Назначение обработчиков событий

Обрабатываемые события:

dragstart — начало перетаскивания
dragend — окончание перетаскивания
dragover — наведение на элемент
dragleave — выход курсора
drop — завершение операции
3. Логика перетаскивания

При начале перетаскивания:

сохраняется текущий элемент
добавляется CSS-класс dragging

При наведении:

добавляется класс over для визуального выделения

При отпускании:

проверяется, что элементы разные
выполняется перестановка через insertBefore
сохраняется новый порядок
4. Метод clearOverStyles()

Удаляет визуальные стили у всех элементов списка.

Используется для очистки состояния после завершения drag-and-drop.

5. Метод getOrder()

Возвращает текущий порядок элементов.

sorter.getOrder();

Результат:
массив значений data-id в текущем порядке отображения.

6. Метод saveOrder()

Сохраняет порядок элементов в localStorage.

Алгоритм:

Получает текущий порядок
Преобразует в JSON
Сохраняет под ключом pageOrder
7. Метод loadOrder()

Восстанавливает порядок элементов из localStorage.

Алгоритм:

Читает сохранённые данные
Парсит JSON
Находит элементы по data-id
Перестраивает DOM в нужном порядке
8. Метод resetOrder()

Удаляет сохранённый порядок из localStorage.

Используется для сброса состояния.

Поток выполнения
Создаётся экземпляр класса
Выполняется поиск списка в DOM
Инициализируются обработчики событий
Загружается сохранённый порядок
Пользователь взаимодействует со списком
При изменении порядка вызывается сохранение
Взаимодействие с DOM

Класс активно использует:

document.querySelector
querySelectorAll
appendChild
insertBefore

Все изменения происходят напрямую в DOM без использования сторонних библиотек.

Работа с localStorage

Данные сохраняются в виде массива:

["1","2","3"]

Ключ хранения:

pageOrder

При загрузке данные используются для восстановления порядка элементов.

Обработка событий

Для реализации drag-and-drop используются стандартные события браузера.

Пример:

item.addEventListener('dragstart', () => {
  this.draggedItem = item;
});

Особенности:

используется предотвращение стандартного поведения (preventDefault)
применяется визуальная обратная связь через CSS-классы
Возможные проблемы
Список не найден
Причина: неверный селектор
Решение: проверить listSelector
Скрипт не работает
Причина: неправильный путь к JS-файлу
Решение: проверить подключение <script>
Порядок не сохраняется
Причина: отключён localStorage
Решение: проверить параметр useLocalStorage
Пример использования
<ul id="page-list">
  <li data-id="1">Главная</li>
  <li data-id="2">О нас</li>
  <li data-id="3">Контакты</li>
</ul>

<script src="../../public/js/PageSorter.js"></script>

<script>
  const sorter = new PageSorter({
    listSelector: '#page-list',
    useLocalStorage: true
  });

  console.log(sorter.getOrder());
</script>
