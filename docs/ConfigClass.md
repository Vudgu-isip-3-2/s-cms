# Конфигурационный класс 

## Общая архитектура

Код реализует класс для работы с конфигурационными файлами:
- Запись параметров в общий массив данных из конфигурационных файлов; 
- Поиск параметров из записанных в массив данных;

## Компоненты

### 1. Структура данных (menuData)
```php
  private array $settings = []; // общий массив со всеми настройками 

```

### 2. Класс Config

#### Конструктор
```php
 public function __construct(string $Path = '.env')
```
- `Path` - Путь в виде строки до конфигурационного файла. Стандартное значение добавляет все .env файлы в каталоге;  
- Вызывает `load()` для загрузки данных в массив; 

#### Методы

##### `load(string $filePath)`
Параметры метода:
- `Path` - Путь в строковом виде до файла с конфигурацией;

Функционал метода:
- Загружает данные (параметры и значения) в общий массив экземпляра класса с сохранением вложенности;
- Может работать с конфигурационным файлами вида `.php`,`.env` и `.ini`;

Пример использования:

```php
$Config->load('C:/Users/Default/Documents/config.php'); // абсолютный путь

$Config->load('../config.ini'); // относительный путь 

$Config->load('config.env'); // в той же папке
```


##### `get(string $key, $default = null)`
Параметры метода:
- `key` - ключ по которому будет происходить поиск параметра. принимает строковое значение и допускает вложенность через точку;
- `default` - значение по умолчанию;

Функционал метода:
- Производит поиск необходимого параметра по ключу и, в случае существования этого ключа возвращает его значение, в ином случае возвращает заданный параметр default ( по умолчанию null-значение);  
- Метод может и предназначен для работы с вложенными данными.

Пример использования:
```php
$host = $Config->get('db.host', 'localhost'); // в данном случае метод вернет либо значение host, если такой существует, либо значение `localhost` 
```

## Пример использования

### Пример файла конфигурации config.ini
```ini
[db]
host = localhost
user = admin
password = 123
```
### Пример PHP кода
```php
// создание экземпляра класса
$config = new Config(); // по умолчанию добавляет все .env файлы

// если нужно загрузить еще настройки из другого файла
$config->load('config.ini');

// получаем данные с помощью метода get()

// пример с вложенностью ключа из файла config.ini
$host = $config->get('db.host'); 

// использование значения по умолчанию, если ключа нет
$port = $config->get('db.port', 3306); 

// можно создать второй независимый экземпляр для других нужд
$config2 = new Config('.php');

```

## Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Контейнер экземпляра класса пустой| В классе есть проверка на существование файла конфигурации, однако сам файл класс не проверяет, поэтому стоит проверить что файл не пустой  |
| Метод `get()` не возвращает необходимого значения, хотя ключ явно существует и написан правильно | Убедитесь, что вы обращаетесь к тому экземпляру класса, в который был записан этот ключ  |

## Производительность

- **Метод Load()**: Сложность: O(n) где n - количество строк или параметров в конфигурационном файле. Строки в файлах парсятся всего один раз;
- **Метод Get()**: Сложность: O(K) где K - количество «сегментов» в ключе (глубина вложенности). Метод не перебирает весь массив целиком, а поиск происходит за константное время;
- **Память**: Сложность: Все настройки хранятся в оперативной памяти в переменной `$settings`. Если конфиг-файл весит 10 МБ, то и массив в памяти будет занимать примерно столько же (с учетом оверхеда PHP на структуры данных).
